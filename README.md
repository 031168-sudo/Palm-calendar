# DateBook

Календарь для Android в духе Palm Date Book + Agendus: у событий есть **тип** (звонок, встреча, задача…) и **контакт** из телефонной книги. Звонок Сергею создаётся в три тапа, без набора текста, а тап по иконке сразу набирает номер.

## Как устроено

- **События** живут в системном календаре Android (`CalendarContract`) → синхронизируются с Google и видны в любом календаре как «Звонок: Сергей».
- **Тип и контакт** хранятся в Room (`eventId → type, lookupKey`) и дублируются меткой `[palm:t=CALL;c=…]` в описании события. Если база потеряется, связи восстановятся из меток.
- Контакт хранится по `LOOKUP_KEY` — он не ломается при слиянии контактов.

## Экраны

- **День**: вкладка с датой и полоса дней недели, часовые строки с пунктиром, иконки типов. Тап по пустой строке — новое событие на этот час. Тап по иконке — действие (позвонить / маршрут), тап по тексту — подробности.
- **Новое**: тип → кто → когда (шаг 15 минут, быстрые «через час / завтра / в понедельник», длительность).
- Кнопки внизу: **Новое · Сегодня · Перейти** — как на Palm.

## Сборка

GitHub Actions собирает debug-APK на каждый пуш в `main`: вкладка **Actions** → последний запуск → **Artifacts**.

Локально: открыть папку в Android Studio (Gradle wrapper она сгенерирует сама).
