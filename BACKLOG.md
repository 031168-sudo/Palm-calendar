# Список исправлений

Копим здесь, делаем пачкой по команде. Правило: сначала обсуждаем, делаем только после «делай».

## iPhone (ветка kmp) — почта (сделано в build kmp-18, ждёт проверки на телефоне)
1. «Ответить»: сначала показываем окно «Скопировано: … — вставьте в поиск почты» с кнопкой «Открыть почту»; почтовая программа запускается только после этой кнопки (и текст в буфер кладётся по ней же). При возврате в DateBook окна подсказки уже нет, остаётся только вопрос «Письмо отправлено?». У «Написать» подсказки нет — письмо открывается сразу.
2. Выбор почтовой программы: в Настройках — пункт «Почта» со сбросом запомненной программы (как на Android). И у «Написать», и у «Ответить» при первом запуске (или после сброса) спрашивать, в какой программе открыть, с галочкой «Запомнить». Сейчас «Написать» сразу открывает программу по умолчанию (mailto), «Ответить» спрашивает и запоминает без возможности сменить.

## iPhone (ветка kmp) — адреса и «Связаться» (сделано в build kmp-22, ждёт проверки на телефоне)
- Свои адреса и «Всегда так для этого человека» теперь сохраняются между запусками.
- «Связаться» на iPhone: список Телефон / WhatsApp / Telegram / Viber (какие установлены), галочка «всегда так».
- Карты на iPhone (build kmp-23): тап по адресу / «Маршрут» предлагает Apple Карты, Яндекс Карты, Навигатор, 2ГИС, Google Карты (какие установлены), галочка «всегда»; сброс — Настройки → Карты.
- Резервная копия на iPhone (build kmp-24): Настройки → Данные: «Сохранить копию» (системное окно «Файлы»/«Поделиться») и «Восстановить» (выбор файла). В копии: настройки, свои адреса, способы связи, адреса и номера контактов, почта и карты. События — в календаре, их копия не нужна. Формат отдельный (`datebook-ios-1`), копии с Android не читает.
