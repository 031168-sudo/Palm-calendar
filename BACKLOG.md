# Список исправлений

Копим здесь, делаем пачкой по команде. Правило: сначала обсуждаем, делаем только после «делай».

## 1. Поле «Название (необязательно)» вместо «Что (можно пусто)» — сделано, ждёт сборки

## 2. Редактирование события из подробностей
- Вверху после типа всегда показывать название события (не только у событий с контактом): «Задача · тест».
- Тап по заголовку — окно правки названия (у событий с контактом — выбор контакта, как «Тип и контакт»).
- Тап по «Когда» — окно правки даты, времени и длительности.
- Тап по «Заметка» — окно правки заметки; если заметки нет — строка «Заметка: добавить…».
- У повторяющихся событий правка относится ко всей серии; события из календарей «только чтение» и дни рождения из контактов не редактируются.
