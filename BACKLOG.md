# Список исправлений

Копим здесь, делаем пачкой по команде. Правило: сначала обсуждаем, делаем только после «делай».

## iPhone (ветка kmp) — почта, делаем по команде «делай»
1. «Ответить»: сначала показываем окно «Скопировано: … — вставьте в поиск почты» с кнопкой «Открыть почту»; почтовая программа запускается только после этой кнопки (и текст в буфер кладётся по ней же). При возврате в DateBook окна подсказки уже нет, остаётся только вопрос «Письмо отправлено?». У «Написать» подсказки нет — письмо открывается сразу.
2. Выбор почтовой программы: в Настройках — пункт «Почта» со сбросом запомненной программы (как на Android). И у «Написать», и у «Ответить» при первом запуске (или после сброса) спрашивать, в какой программе открыть, с галочкой «Запомнить». Сейчас «Написать» сразу открывает программу по умолчанию (mailto), «Ответить» спрашивает и запоминает без возможности сменить.
