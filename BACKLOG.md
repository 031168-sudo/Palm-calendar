# Список исправлений

Копим здесь, делаем пачкой по команде. Правило: сначала обсуждаем, делаем только после «делай».

## 1. Все календари в выборе «Куда записать?» с пометками
Сейчас «Мой календарь» (основной календарь 031168@gmail.com) и «Понятаев» не видны; причина — фильтр по признаку «видимый» в Android.
- Показывать все календари телефона, не только «видимые» по мнению Android.
- Непригодные внизу, серым, с пометкой почему: «синхронизация выключена», «только чтение», «только на этом телефоне».
- Если синхронизация выключена — подсказка, где включить (в Google Календаре: Настройки → календарь → Синхронизация).
- Локальный календарь (local account / Основной) подписывать «только на этом телефоне», ставить в конец или не предлагать для записи.

## 2. Показывать события «невидимых» календарей
- Убрать фильтр VISIBLE при загрузке событий, чтобы события «Моего календаря» появились в днях/неделе/месяце.

## 3. Выбор, какие календари показывать
- Галочки по календарям, как в Google Календаре (например, скрыть Праздники из дня).
- Дни рождения и Праздники — только чтение, для записи не предлагаются (так и задумано). Задачи Google (Tasks) Android сторонним приложениям не отдаёт.
